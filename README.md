# Sylando

A SwiftUI e-commerce app for browsing and managing T-shirt products.

## Overview

Sylando was created as part of my iOS development training.

The application demonstrates the structure of a simple online shop where users can browse products and work with product information.

## Technologies

- Swift
- SwiftUI
- SwiftData
- Xcode

## Features

- Browse T-shirt products
- Display product information
- Search and filter products
- Work with persistent data
- Structured product presentation

## What I Practiced

- Building an e-commerce interface with SwiftUI
- Working with SwiftData
- Creating reusable SwiftUI views
- Managing application state
- Working with data models
- Building structured layouts for product information
